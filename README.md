# Программа сбора данных о самолетах.

## Описание:

Программа собирает данные о самолетах в воздушных пространствах выбранной страны.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/VanAlex278/VanAlex278Repo
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

Имеются следующие функций:

- Поиск координат страны по её названию:
- Сбор данных о самолетах, находящихся в воздушном пространстве данной страны
- Сортировка, фильтрация и сравнение данных о самолетах
- Чтение, запись и удаление данных о самолетах в json-файл 

## Тестирование:

Все функции проекта протестированны с помощю pytest.
